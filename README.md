# Retro Cafe Website

A retro-inspired website for Retro Cafe in Scranton, Pennsylvania.

## Project Overview

This project features a warm, vintage-inspired design with a cream, red, and turquoise color palette.

The website includes:
- Hero section
- Coffee menu with prices
- About section
- Photo gallery
- Contact information
- Responsive styling for mobile devices

## How to Run the Website

1. Open the project folder in Visual Studio Code.
2. Open `index.html` in a browser, or use the Live Server extension.
3. Edit the HTML, CSS, or JavaScript files as needed.
4. Refresh the browser to view changes.

## Editing the Website

- **Content and sections:** `index.html`
- **Colors, layout, and responsive styles:** `style.css`
- **Interactive behavior:** `script.js`
- **Photos and other images:** `assets/images/`
- **Browser tab icon:** `favicon.png`
